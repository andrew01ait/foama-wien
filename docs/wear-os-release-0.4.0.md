Gespeicherte PWA-Routen per bestehendem zehn Minuten gültigem QR-Transfer bewusst übernehmen. Favoriten zeigt Routen neben bestehenden Stationen. Route zeigt Einstieg und nächsten Umstieg mit aktuellen exakt zugeordneten Linienzeiten; Weiter/Vorheriger Einstieg und Alle Abfahrten mit passendem Zurück-Pfad. Neue Seiten oben, laufender Refresh erhält Leseposition. Keine native Vollplanung, alten Fahrzeiten, gespeicherten GPS-Fixes oder neue Hintergrundabfragen. Ältere Stations-QR-Pakete bleiben v1-kompatibel, neue Routes werden als v2 ausgetauscht. Anzeige alter Linienwege garantiert keine konkrete Fahrt/Anschluss.
